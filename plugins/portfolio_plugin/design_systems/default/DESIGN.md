# Whiskers Agent portfolio design system (default)

## Voice
- Precise, systems-minded, peer-to-peer. Avoid generic AI portfolio clichés.
- Prefer concrete architecture and multi-tenant/MCP proof over buzzwords.

## Band intent (matrix L0–L7)
Mirrors the canonical `composer._DAG_LEVEL_BY_TYPE` map — keep these in sync.
- L0 Intro: hero + identity
- L1 Impact: KPI / proof metrics from real project data
- L2 Projects: domain cards (scoped, not whole inventory dump)
- L3 Architecture: flowAnim (agent/system motion) + archDiagram + mcpSandbox (interactive, zero grounding)
- L4 Charts: chart (metrics-derived) + comparison + costSim (interactive, zero grounding)
- L5 Proof: timeline + STAR stories with real tags
- L6 Deep dive: single-column composite/prose/codeSnippet with citations
- L7 Ask: quickActions when available (CTA band)

## Anti-patterns
- Template-mode whole-portfolio dump for a scoped ask
- Fake metrics or uncited prose claims
- Dense 12-col walls of identical cards without rhythm
- Free HTML / iframe artifacts on public HR pages

## Domain colors
- Prefer theme presets cozy | neon | paper | latte | frappe | macchiato | mocha; override via tokens only.
